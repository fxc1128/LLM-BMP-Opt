# Youwuzhen SEIMS Example

Restore data/seims/youwuzhen/mongo_dump into MongoDB at 127.0.0.1:27017. Copy data/seims/youwuzhen/scenario_config into runs/seims_youwuzhen/model before running an optimization. Set SEIMS_PATH to external/seims/python and add external/seims/bin to PATH.

The profile youwuzhen_seims_sediment uses the three restored 30 m databases. No historical scenario output is included.
